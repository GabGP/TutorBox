# TutorBox Infrastructure & Deployment

Deployment scripts, service configurations, and networking setup.

## Components
* **BeagleBone Black (BBB)**: Nginx web server and reverse proxy configurations.
* **Jetson Orin Nano**: Systemd service units for `llama.cpp` server, FastAPI app, and local kiosk dashboard.
* **Network & Router**: GL.iNet GL-AR300M16 AP configurations.
